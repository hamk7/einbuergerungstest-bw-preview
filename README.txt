Einbürgerungstest BW – Version 3.5 PREVIEW

Neu in 3.5:
- 298 offizielle BAMF-Fragegrafiken direkt in der App eingebettet.
- 12 BAMF-Fragen ohne Grafik werden im auf der BAMF-Seite verwendeten fetten Arial-Stil dargestellt.
- Digitale Prüfung verwendet diese BAMF-Originaldarstellung immer als Standard.
- Papiertest/PDF verwendet dieselbe Darstellungsquelle; alte separate Fragebilder werden nicht mehr doppelt angezeigt.
- PDF-Fragensatz ist von der alten V3.1-Papierlogik entkoppelt und wird als 30 allgemeine + 3 BW-Fragen validiert.
- PDF-Engine kann die gesammelten RGB-PNGs direkt in die PDF einbetten (keine Ganzseiten-Canvas-Konvertierung).
- Lernmodus: BAMF-Originaldarstellung kann über den vorhandenen Schalter optional aktiviert werden.
