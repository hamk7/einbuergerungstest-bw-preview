Einbürgerungstest BW – Version 3.7.4 PREVIEW

Änderungen gegenüber 3.7.3:

1. Nach PDF-Erstellung:
   - Die PDF wird weiterhin direkt geöffnet.
   - Erst NACH erfolgreicher PDF-Erzeugung wird im ursprünglichen Tab
     automatisch die Kontrolle exakt dieses letzten 33-Fragen-Bogens geöffnet.
   - Wenn man aus der PDF zurückgeht, kann man deshalb sofort kontrollieren.
   - Vor einer PDF-Erstellung erscheint diese Kontrolle nicht.

2. Fehler behoben:
   - Eine zuvor über Statistik/Prüfungsverlauf geöffnete Papierkontrolle bleibt
     nicht mehr stehen, wenn anschließend eine digitale Prüfung gestartet wird.
   - Sobald irgendeine digitale Prüfung läuft, wird die Papierkontrolle zentral
     geschlossen.
   - Das gilt auch für digitale Wiederholungen aus dem Prüfungsverlauf.

PDF-Kern, 30+3-Zufallsauswahl, Nur-Fragen-Schalter und Statistiklogik bleiben
gegenüber 3.7.3 unverändert.
